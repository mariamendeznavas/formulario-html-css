# Formulario de reserva de hotel (HTML y CSS)

Ejercicio del ciclo de Desarrollo de Aplicaciones Web: página con un formulario de petición de reserva de hotel.

**Ver la web:** https://mariamendeznavas.github.io/formulario-html-css/

## Qué incluye
- Agrupación de campos con `fieldset` y `legend`.
- Campos de texto, teléfono, correo y número.
- Listas desplegables (`select`) para día y mes de entrada.
- Botones de radio (tipo de habitación) y casillas de verificación (servicios adicionales).
- Área de texto con límite de 250 caracteres.
- Etiquetas asociadas a cada campo (`label for`).
- Validación nativa del navegador (`required`, `min`, `max`, `maxlength`).
- Botones de enviar y de limpiar el formulario.

## Tecnologías
HTML5 · CSS3 · GitHub Pages

## Nota
Es una página estática: el formulario no envía ni guarda datos.
